#  🚀 Proyectos de Manipulación del DOM

Colección de proyectos prácticos enfocados en el aprendizaje, la práctica y el dominio de la **Manipulación del DOM (Document Object Model)** utilizando JavaScript moderno (ES6+), HTML5 y CSS3.

---

## 🎯 Objetivo del Repositorio
Este repositorio sirve como bitácora de aprendizaje y portafolio para consolidar los fundamentos de la interacción con páginas web dinámicas sin necesidad de frameworks externos. Cada proyecto aborda conceptos clave como selección de elementos, manejo de eventos, modificación de atributos, estilos dinámicos y creación de componentes interactivos.

## 💡 Conceptos Clave Aplicados
A lo largo de estos proyectos se ponen en práctica los siguientes temas fundamentales:
* **Selección de Elementos:** `getElementById`, `querySelector`, `querySelectorAll`.
* **Modificación de Contenido:** `textContent`, `innerHTML`, manipulación de clases con `classList` (`add`, `remove`, `toggle`).
* **Manejo de Eventos:** `addEventListener` para clics, entradas de teclado (`keyup`, `keydown`), entre otros.
* **Creación y Eliminación de Elementos:** `createElement`, `appendChild`, `removeChild`, `remove`.

## 🛠️ Requisitos Previos
Para ejecutar y probar cualquiera de estos proyectos en tu máquina local, solo necesitas:
* Un navegador web moderno (Google Chrome, Firefox, Edge, etc.).
* Un editor de código (como **Visual Studio Code**).
* (Opcional) La extensión **Live Server** en VS Code para recargar la vista previa automáticamente.

---

## 🚀 ¿Cómo Ejecutar los Proyectos?

1. Clona este repositorio en tu computadora:
   ```bash
   git clone https://github.com/davidleandrosanchezpuentes-debug/proyectos-javascript-DOM.git
   ```
2. Entra a la carpeta del proyecto que deseas probar:
   ```bash
   cd proyectos-javascript-DOM/nombre-del-proyecto
   ```
3. Abre el archivo `index.html` en tu navegador preferido o utilízalo con *Live Server*.
